# Tenders-pro-dz

تطبيق أندرويد عربي لمتابعة المناقصات والاستشارات في الجزائر، مع خادم API قابل للنشر.

## بناء APK
يتم البناء تلقائياً عبر GitHub Actions عند الدفع إلى هذا الفرع أو تشغيل workflow يدوياً. ملف APK يظهر في Artifacts بعد نجاح البناء.

## الخادم
انشر مجلد backend عبر Render باستخدام render.yaml. نقاط API:
- GET /health
- GET /api/tenders
- POST /api/tenders

**تنبيه:** هذه نسخة أولية. الإعلانات الظاهرة داخل التطبيق تجريبية، ولم تتم إضافة مصادر رسمية أو جمع آلي للإعلانات بعد.
